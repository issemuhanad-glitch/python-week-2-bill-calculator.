# Simple Bill Calculator

## Description

This Python program calculates the total cost of items based on the price of one item and the quantity purchased.

## How It Works

1. The program asks the user to enter the price of one item.
2. The program asks the user to enter the quantity.
3. The price is converted to a float.
4. The quantity is converted to an integer.
5. The program calculates the total cost.
6. The result is displayed using an f-string.

## Example

If the user enters:

- Price: 50
- Quantity: 3

The program displays:

`3 items at 50.00 each = 150.00.`
